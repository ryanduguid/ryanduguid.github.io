usage: site-tools check_site [-h] [--offline] [--ci] [--ci-metadata-only]

Run every repository-defined site check through one documented command.

options:
  -h, --help          show this help message and exit
  --offline           skip live external-link checks
  --ci                select live checks from the pull-request diff; pull
                      requests warn on transient link failures
  --ci-metadata-only  print the browser CI selection only
