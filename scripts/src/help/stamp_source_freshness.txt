usage: site-tools stamp_source_freshness [-h] [--write | --check-releases | --write-tool-releases | --build]

Check or refresh the tool source freshness stamps and release references.
With no option, check the stamps in tools/index.html.

options:
  -h, --help             show this help message and exit
  --write                refresh the stamps from each source's last commit date on GitHub
  --check-releases       check the changelog and tool pages against the published GitHub releases
  --write-tool-releases  refresh _data/tool_releases.json and the pages that name a release
  --build                --write-tool-releases, then build the site
