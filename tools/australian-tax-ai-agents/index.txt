# Australian tax MCP server: Aus Accounting MCP

aus-accounting-mcp runs local Australian accounting checks through the Model Context Protocol. It covers ATO benchmarks, Payday Super timing, limited Division 7A review and 7 bounded tax worksheets. It can also search a Markdown folder you configure. Outputs need human review.

Reference release v0.2.8, the current published release, verified 24 September 2026. Tagged source and release record on GitHub.

Published 25 August 2026. Last reviewed 24 September 2026. This review verifies the 0.2.8 release, which keeps the 0.2.8 engine pins (ato-benchmark-compare 0.1.9, australian-tax-calculators 0.1.5), ranks local legislation search results best first and reads long provisions in parts; network boundaries remain unchanged.

Choose the tool by the work it supports: a calculation on established facts, a source lookup or an accounting workflow. Ryan Duguid, an accountant in Newcastle, NSW, publishes the local engines and the MCP server that runs them. The server ships no ATO document library and does not retrieve rulings from the web.

Job | What to install | Where it runs | What it will not do

Look up ATO guidance, legislation and public rulings | A document-retrieval MCP such as ato-mcp | Typically a hosted remote MCP | Not a reviewed calculator for Payday Super timing or ATO benchmark ratios
Walk an agent through a public practice workflow | australian-accounting-skills | Claude Code / Codex plugin, or npx --yes skills@1.5.22 add | Does not treat recorded figures as current rates. Sends the agent to the applicable authoritative source for current figures.
Bounded GST, resident tax, CGT, FBT, depreciation, quarterly SG or PAYG withholding arithmetic | Aus Accounting MCP with australian-tax-calculators | Local MCP | No HELP, Medicare, offsets, scale 4 or irregular-pay PAYG withholding, or full tax return preparation. Each worksheet requires established facts and a supported period.

Those other projects are named so an agent can tell them apart. This page does not review them, and it does not speak for their authors.

## What aus-accounting-mcp does

- Lists and searches the shipped ATO small business benchmark industries.
- Compares the profit and loss buckets you supply to the published ATO ranges. Omitted buckets stay not_supplied; they are not treated as zero.
- Reviews one Payday Super contribution or a related group for one employer, using payday-super-checker. Missing fund receipt evidence remains unresolved.
- Reviews s 109N loan terms and s 109E minimum yearly repayments for one supplied amalgamated loan. Division 7A review is experimental and requires human review.
- Calculates 7 experimental tax worksheets through calculate_tax_worksheet, with explicit scope and period checks.
- Searches and reads a configured local Markdown library with file and line citations. This is optional; the package includes no library.
- Emits synthetic SBR fixtures for agent tests, labelled synthetic: true.

Payday Super and ATO benchmarks are delegated to reviewed engines, payday-super-checker and ato-benchmark-compare. The MCP server does not reimplement the law.

The worksheet scope and periods are fixed by australian-tax-calculators 0.1.5, the engine published release 0.2.8 pins. Resident basic tax covers full-year resident ordinary income for 2024-25, 2025-26 and 2026-27, before offsets and levies. GST, CGT, depreciation and quarterly SG cover bounded 2025-26 cases; FBT covers the year ended 31 March 2026. The quarterly SG worksheet does not calculate post-June 2026 Payday Super entitlements. PAYG withholding covers one regular weekly, fortnightly or monthly pay from 1 July 2026 on Schedule 1 scale 1, 2, 3, 5 or 6, before tax offsets and Medicare levy adjustments.

Read aus-accounting://scope before confirming worksheet inputs. Keep the exclusions returned with each result. The release instructions also explain optional local library setup. Any retrieved excerpts enter the calling assistant's context.

## Primary sources

Payday Super timing draws on the Superannuation Guarantee (Administration) Act 1992 and Australian Taxation Office, LCR 2026/2. Benchmark comparisons use the ATO's small business benchmarks. The limited Division 7A review applies sections 109N and 109E of the Income Tax Assessment Act 1936.

Each engine's source review and release record state what was checked. Verify current sources and the supplied facts before using an output.

## Try two synthetic tool calls

With uv installed, run the published demonstration without configuring an AI client:

```
uvx --from aus-accounting-mcp==0.2.8 aus-accounting-mcp-demo
```

Expected: exit 0 and a JSON transcript containing generate_synthetic_sbr_fixture and review_div7a_loan. The demonstration calls the local tools with fictional facts. It needs no credentials, performs no lodgement and does not evaluate an agent's behaviour.

The transcript's first line shows the source-checkout command, uv run --locked aus-accounting-mcp-demo. The command above runs the published 0.2.8 package. Its full output includes the engine's caveats; retain those with any extracted result.

## Limits

The calculation engines and MCP server run locally. Installation downloads packages. If you use a cloud-backed AI host, supplied arguments, tool results and local library excerpts may be sent to that host's model provider. Check the host's configuration and data handling before supplying information.

The optional LodgeiT calculator adapter is separate, unreleased development code and off by default. It makes network calls only with explicit enablement, a configured base URL and an allowed host. The standard MCP server does not use it as a fallback. Website hosting and browser data handling have their own boundaries.

Published MCP 0.2.8 pins Payday Super Checker 0.1.7. A timely receipt date without an amount remains UNKNOWN; a late receipt without an amount cannot reduce the shortfall. Older MCP 0.2.4 pins checker 0.1.6 and retains its full-receipt assumption. Review the version-specific receipt rules before interpreting a result.

Not tax, legal or financial advice, and using it creates no professional relationship. The tools calculate and refuse. Professional judgement and lodgement stay human. Tool results and any local library excerpts enter the calling assistant's context. Public fixtures use synthetic data only.

## Common questions

### What is aus-accounting-mcp?

A local Model Context Protocol server for ATO benchmark comparison, Payday Super timing, limited Division 7A review, 7 bounded tax worksheets and optional search of a configured Markdown library. Outputs need human review.

### Is aus-accounting-mcp a hosted ATO document library?

No. It ships no ATO document library and does not fetch rulings or legislation from the web. You can configure a local Markdown folder for search and reading with file and line citations. Retrieved excerpts enter the calling assistant's context.

### Does it calculate Division 7A repayments?

It reviews s 109E minimum yearly repayments for one supplied amalgamated loan. This is experimental and requires human review. It refuses loan formation, s 109R repayment classification, unpaid present entitlements and distributable surplus.

### Does it lodge with the ATO?

No. It does not lodge, declare or replace a registered agent. SBR payloads it can emit are synthetic test fixtures.

### When is a Payday Super contribution on time?

Since 1 July 2026, the fund must receive it within 7 business days of payday, or 20 business days for a first contribution to a new fund. Sending money to a clearing house does not stop the clock.
