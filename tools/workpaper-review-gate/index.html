Workpaper Review Gate for manager review packs

This tool inspects a folder of workpapers and answers READY, NOT_READY or BLOCKED. A missing GST control export, an unsigned self-review, or a trial balance that does not balance never reaches the manager.

On this page

What this tool does Limits Get it Common questions Related

Preparation got cheaper. Review did not. Offshore teams, juniors and AI agents can produce a file faster than a manager can reconstruct it. Most of what then happens on the review desk is not judgement: it is finding the missing tie-out, the open item still sitting in email, the same error as last period.

Point the CLI at a pack directory. It checks that the required artefacts are present, that the preparer has certified the pack, that blocking open items are cleared, that the trial balance balances, and for a BAS that 1A less 1B ties to the GST control movement. A READY pack may enter manager review. The tool still does not decide that the work is correct.

What this tool does

  • Gates BAS, month-end and year-end packs before they reach a reviewer.
  • Writes a cover sheet, a findings CSV and a hashed JSON pack a manager can archive.
  • Flags findings that were still OPEN on the prior pack as repeats.

Limits

Local files only. No Xero connection, no lodgment, no LLM, no period lock. A READY result is not sign-off.

Common questions

Is READY the same as approved?

No. READY means no configured gate tripped on the files that were present. A human still decides whether the file can be signed or lodged.

Does this replace monthly close review?

No. Monthly Close Controls still produces the exception pack once a trial balance is allowed onto the desk. This tool sits upstream of that.

Can it change a client's ledger?

No. It reads local files and writes a readiness pack. It cannot post, pay, lodge or lock a period.
