Using these functions

Each function is a native Excel LAMBDA in the free Ozzit workbook. It needs Microsoft 365 or Excel 2024 or later. Enter a call in a cell of the workbook, or copy the definition from its name manager into your own model. Leave room for any spilled result.

The text below is the help each function carries in the v3.5.0 workbook. The workbook remains the authority, and a calculation does not decide an accounting treatment. Download the workbook and check its hash.

oz.CountCλ

oz.CountCλ( Text, Characters)

Count occurrences of character(s) in a string

Count how many of one or more characters are in a string.

Parameters:

Text (required)
The string to interrogate. Empty text returns 0
Characters (required)
A single character, or CSV of characters to find in Text NOTE! Case sensitive. A single character is taken as itself, so a comma works
=oz.CountCλ( "Mary had a little lamb", "a,b")

oz.IsBetweenEλ

oz.IsBetweenEλ( Value, Low, Hi, [Inclusive])

Determine if a value is between a lower and upper limit

Determine if a value is between a lower and upper limit.

Parameters:

Value (required)
A value or array of values to compare.
Low (required)
The lower limit that the value must be greater than
Hi (required)
The higher limit that the value must be less than
Inclusive (optional)
If set to TRUE (default) the value can be equal to Low and/or Hi
=IsBetweenEλ(1, 2, 4)

The workbook help shows FALSE.

=IsBetweenEλ(2, 2, 4)

The workbook help shows TRUE.

=IsBetweenEλ(2, 2, 4, FALSE)

The workbook help shows FALSE.

Previous name: nabla.e.IsBetweenλ.

oz.IsInListλ

oz.IsInListλ( Value, List)

Determine whether a value is one of a list of items

Determine if a value is one of a list of items.

Note: The comparison is exact and case-insensitive; * and ? are ordinary characters.

Parameters:

Value (required)
A value or array of values to compare.
List (required)
A list of values to check: a row, a column or a grid.
=IsInListλ(1, {2,3,4})

The workbook help shows FALSE.

=IsInListλ(1, {1,3,5})

The workbook help shows TRUE.

Previous name: nabla.e.IsInListλ.
