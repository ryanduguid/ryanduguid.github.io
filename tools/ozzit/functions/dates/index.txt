# Ozzit Dates functions

The 15 Dates formulas cover periods, timelines, schedules, overlaps and Australian financial year labels. Each entry gives the signature, parameters and worked example from the workbook’s own help.

Release v3.5.0. Read from the released Dates formula source, which the workbook compiles.

Published 20 October 2026. Last reviewed 20 October 2026.

## Using these functions

Each function is a native Excel LAMBDA in the free Ozzit workbook. It needs Microsoft 365 or Excel 2024 or later. Enter a call in a cell of the workbook, or copy the definition from its name manager into your own model. Leave room for any spilled result.

The text below is the help each function carries in the v3.5.0 workbook. The workbook remains the authority, and a calculation does not decide an accounting treatment. Download the workbook and check its hash.

### oz.CountDOWλ

oz.CountDOWλ(Starts, Ends, DayOfWeek)

Count instances of a specific day of the week between two dates.

Parameters:

Starts (required)

One of more start dates (text or numeric) in a row or column

Ends (required)

End dates (text or numeric) for each start date

DayOfWeek (required)

1=Sunday, 7=Saturday.

```
=oz.CountDOWλ("23/7/2026", "11/8/2026",  1)
```

The workbook help shows 3.

### oz.IsOccurrenceDateλ

oz.IsOccurrenceDateλ(Dates, FirstOccurrence, [LastOccurrence], [Repeats])

Returns TRUE if Date passed is when something happens. This was developed for budgeting where we have expenses that start, and sometimes repeat at regular intervals.

Returns TRUE if a Date is when something happens. This was developed for budgeting where we have expenses that start, and sometimes repeat at regular intervals.

Note: A monthly, quarterly, semi-annual or annual item that starts on the 29th, 30th or 31st falls on the last day of any shorter month.

Parameters:

Dates (required)

Date to test. Normally this is horizontal timeline by day

FirstOccurrence (required)

When something that may repeat, happens for the first time.

LastOccurrence (optional)

When something that may repeat, happens for the last time. If omitted, it is assumed repeating items repeat forever.

Repeats (optional)

A code that conveys how often this thing repeats. Repeat codes are O=One time/never repeats (default) A=Annually S=Semi-Annually Q=Quarterly M=Monthly B=BiWeekly W=Weekly X=Every Workday (Monday to Friday) D=Daily

```
=SUM(N(oz.IsOccurrenceDateλ(SEQUENCE(,90,"1/7/2026"), "1/7/2026", "10/9/2026", "D")))
```

The workbook help shows 72.

```
=SUM(N(oz.IsOccurrenceDateλ(SEQUENCE(,90,"1/7/2026"), "1/7/2026", "10/9/2026", "O")))
```

The workbook help shows 01.

```
=SUM(N(oz.IsOccurrenceDateλ(SEQUENCE(,90,"1/7/2026"), "1/7/2026", "10/9/2026", "W")))
```

The workbook help shows 11.

Previous name: nabla.d.IsOccurrenceDateλ.

### oz.PeriodLabelλ

oz.PeriodLabelλ(Date, [Interval])

Creates a label for a date based on period interval

Parameters:

Date (required)

A single date or array of date(s) where the first date is the first date of a calendar year.

Interval (optional)

Must be one of:

- D=Daily
- W=Weekly
- I=Weekly (using ISO week number)
- M=Monthly
- Q=Quarterly
- S=Semi-Annually
- A or Y=Annually

```
=oz.PeriodLabelλ(DATEVALUE("26/8/2026"), "Q")
```

The workbook help shows 2026:Q3.

```
=oz.PeriodLabelλ(DATEVALUE("26/8/2026"), "Y")
```

The workbook help shows 2026.

### oz.Periodsλ

oz.Periodsλ(Starts, Ends, [Intervals])

Determine the number of periods from Starts to Date2 in Days, Weeks, Months, Quarters, or Years.

Determine the number of periods from Starts to Ends inclusive. Differences to Excel's DATEDIF are: * Interval includes Weeks & Quarters * Counts the period starts crossed, so a part period at the end counts * Returns negative values if Starts is after Ends

Parameters:

Starts (required)

First date (normally older). A single date or an array of dates.

Ends (required)

Second date (normally newer). A single date or an array the same shape as Starts. A single Starts or Ends is applied to every date in the other.

Intervals (optional)

Days, Weeks, Months (default), Quarters, or Years (D, W, M, Q, Y). One code, or an array of codes the same shape as the dates.

```
=oz.Periodsλ("31/7/2026", "15/9/2026")
```

The workbook help shows 2.

```
=oz.Periodsλ("15/9/2026", "31/7/2026")
```

The workbook help shows -2.

```
=oz.Periodsλ("15/7/2027", "16/7/2026")
```

The workbook help shows -12.

```
=oz.Periodsλ("15/7/2027", "16/7/2026", "W")
```

The workbook help shows -52.

Previous name: nabla.d.Periodsλ.

oz.ScheduleRatesλ(PeriodEnds, RateStarts, Rates)

Schedule rates that persist until replaced in a timeline.

Schedules rates that persist until replaced in a timeline from a schedule in a table.

Note: If 2 rates are scheduled within the same period, only the last rate will be selected.

Parameters:

PeriodEnds (required)

A row of period end dates (timeline).

RateStarts (required)

Rates (required)

A column or row of rates associated with RateStarts.


### oz.ScheduleRatesByItemsλ

oz.ScheduleRatesByItemsλ(PeriodEnds, ItemFilter, ItemList, EffectiveList, RateList)

Schedule rates that persist until replaced in a timeline for each item in a list.

Schedules each item's rates by period until another rate takes effect.

Note: If 2 rates are scheduled within the same period for the same item,. only the last rate will be selected.

Parameters:

PeriodEnds (required)

A row of period end dates (timeline).

ItemFilter (required)

A column of 1 or more items to filter a rate schedule by. A 'rate schedule' is a table/list where each row contains a unique item/effective date pair with a rate. An item with no rate in the schedule scores nought in every period.

ItemList (required)

Items in a rate schedule.

EffectiveList (required)

Effective dates in the rate schedule.

RateList (required)

Rates in a rate schedule for each item/effective date pair.

```
=oz.ScheduleRatesByItemsλ( oz.Timelineλ( "1/7/2026"), UNIQUE( tblRates[Unit]),
tblRates[Unit], tblRates[Effective], tblRates[Rent])
```

Previous name: nabla.d.ScheduleRatesByItemsλ.

### oz.RateAtDateλ

oz.RateAtDateλ(EffectiveDates, Rates, Dates)

Returns the rate in effect on each date from a table of effective dates and rates, refusing gaps, unsorted or repeated dates

Returns the rate in effect on each date from your table of effective dates and rates.

Note: Each rate applies from its effective date until the next one. Dates may be one date or a row or column of them, and the result takes their shape. A date before the first effective date has no rate in effect and returns #N/A. The table must be complete and in order, so instead of a result it returns a message when EffectiveDates and Rates differ in length or hold a blank or text entry, when the dates are not in ascending order, or when a date repeats. A text or blank date in Dates returns #VALUE!. The library ships no rate table: supply your own, with its source and the date you checked it. ScheduleRatesλ() lays rates across a timeline without these checks.

Parameters:

EffectiveDates (required)

A row or column of dates from which each rate applies, in ascending order.

Rates (required)

The rate that applies from each effective date, the same length as EffectiveDates.

Dates (required)

The date, or a row or column of dates, to look up.

```
=oz.RateAtDateλ(DATE(2026, {1;7;10}, 1), {0.04;0.045;0.05}, DATE(2026, 8, 15))
```

The workbook help shows 0.045.

### oz.DateDifλ

oz.DateDifλ(StartDate, EndDate, [Unit])

Whole years, months or days between two dates, and the remainders DATEDIF gets wrong

Whole years, months or days between two dates, and the remainders.

Note: Excel documents DATEDIF as a legacy compatibility function and warns its MD unit can return a negative or wrong day count. This counts a month as complete when EDATE() of the start date has arrived, so a month after 31 January is the last day of February, and takes every remainder from there. A reversed range or an unknown unit returns #NUM!.

Parameters:

StartDate (required)

The earlier date, numeric or text.

EndDate (required)

The later date, numeric or text.

Unit (optional, Default = D)

Y whole years, M whole months, D days, YM months left after the whole years, YD days left after the whole years, MD days left after the whole months.

```
=oz.DateDifλ(DATE(2026,1,31), DATE(2026,3,1), "MD")
```

The workbook help shows 1.
