# Mineral processing and metallurgical laboratory assets / Sample preparation assets / Drying ovens: Benchtop (Scientific testing and analysis services)

‘Drying ovens: Benchtop’, for an asset used in Scientific testing and analysis services, has an effective life of 7 years under the Commissioner’s 2025 effective life determination (F2025L01097), last reviewed and determined on 1 July 2019.

## Reading this row

In Scientific testing and analysis services, this life applies if the asset matches the row exactly or is of a kind that falls within or broadly satisfies the function described (subsection 6(2)). In another industry, use its applicable Table A life. If none applies, use the matching Table B row (subsection 6(3)).
