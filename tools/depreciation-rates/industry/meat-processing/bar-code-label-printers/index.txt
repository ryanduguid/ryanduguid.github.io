# Packaging assets: Bar code label printers

‘Packaging assets: Bar code label printers’, for an asset used in Meat processing, has an effective life of 3 years under the Commissioner’s 2025 effective life determination (F2025L01097), last reviewed and determined on 1 July 2013.
