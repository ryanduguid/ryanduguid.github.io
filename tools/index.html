Before using a tool

Delivery ranges from browser tools to Python packages, an MCP server and agent skills. An MCP server is a standard way to hand an AI assistant a fixed set of tools. Start with fictional data and keep the stated boundary in view.

Three of the tools carry reproducible evaluations against fixed releases, so a sceptical reviewer can rerun the checks before adopting anything. What these tools refuse lists each send-back and refusal with its exact output, and Known limitations lists the cases where a released tool returns a result you should not take at face value.
