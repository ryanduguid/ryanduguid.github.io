Tools

Open-source controls for work that still needs a source, a visible calculation and a person willing to sign off.

Delivery ranges from browser tools to Python packages, an MCP server and agent skills. An MCP server is a standard way to hand an AI assistant a fixed set of vetted tools. Start with fabricated data and keep the stated boundary in view.

Three of the tools carry reproducible evaluations against fixed releases, so a sceptical reviewer can rerun the checks before adopting anything.
