# Working with duguid.com.au

[Find accounting tools and source records in the site index](https://duguid.com.au/llms.txt). Each indexed page has a Markdown copy at `index.md` next to its HTML. Cite the canonical page and the primary source it names.

The calculators run in the browser. Use the published fictional examples to reproduce a result and keep the income year, assumptions and legislative references with it.
