Calculations through Aus Accounting MCP

Aus Accounting MCP gives a compatible Claude client a local set of calculation and review tools, including ATO benchmark comparison, Payday Super timing and bounded tax worksheets. The current release is v{{ mcp.version }}.

Use Claude Code or Claude Desktop with a local stdio server. This server has no hosted endpoint that you can paste into Claude’s web app. The released client integration guide shows the local configuration.

Preparation through accounting skills

The released Australian Accounting Skills v{{ skills.version }} gives Claude Code workflows for preparing and checking workpapers. The subcontract ledger guide covers progress claims, retentions and WIP preparation.

Skills are instructions used by the agent. They do not disable the agent’s other tools or enforce its permissions. Review the agent’s file, command and external-service access separately.

Set up and try

  1. For MCP in Claude Code: install Python 3.14 or later and uv, then open the installation guide and choose the Claude Code tab. Check the installed version; the unpinned command may reuse a cached package.
  2. For MCP in Claude Desktop: use the same Python and uv prerequisites with the local stdio configuration in the released README.
  3. For skills in Claude Code: use Git, Node and a working Claude Code installation. Choose Skills in the installation guide to copy the tagged release into a project. This route does not start the MCP server.

Try the fictional MCP demonstration before supplying your own figures. It runs a pinned historical release outside Claude, so you can inspect the expected tool output separately from an assistant’s explanation. Retain the version and caveats with the result.

For a skills walkthrough, follow the released BAS preparation example. Check its required inputs and expected tie-outs before asking Claude Code to prepare a workpaper.

Refusals and human review

Review required: calculations and prepared workpapers require human review before posting, payment, lodgement, approval or period lock. These tools provide no tax, legal or financial advice.

Aus Accounting MCP is separate from the hosted ATO retrieval project, ato-mcp. It ships no ATO document library and does not fetch legislation or rulings from the web. A configured local library sends its retrieved excerpts back into Claude’s context.

Division 7A support is experimental. The server provides benchmark interest rate lookup and reviews s 109N loan terms and s 109E minimum yearly repayments for one supplied amalgamated loan. It refuses loan formation, s 109R repayment classification, unpaid present entitlements and distributable surplus. Read the refusal register and the tool’s period and scope checks with each result.
