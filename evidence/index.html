Data and privacy boundary

The calculation engines and MCP server run locally. Installation downloads packages. If you use a cloud-backed AI host, supplied arguments, tool results and local library excerpts may be sent to that host's model provider. Check the host's configuration and data handling before supplying information.

The optional LodgeiT calculator adapter is separate, unreleased development code and off by default. It makes network calls only with explicit enablement, a configured base URL and an allowed host. The standard MCP server does not use it as a fallback. Website hosting and browser data handling have their own boundaries.

No client, taxpayer or production-ledger data appears in public examples. Business fixtures are synthetic; dated official-source snapshots are identified separately and do not establish current law. Client data belongs in a controlled local directory, never a public issue, repository or enquiry email.

  • The ATO benchmark client data control records the zero-network runtime boundary.
  • The Payday Super local file boundary, TheWIPTally local file boundary and Workpaper Review Gate data boundary state how client files are separated from public fixtures.
  • The MCP client architecture describes a local stdio process. The Xero scope and credential boundary separately records that product's read-only API and local token controls.
  • The Coal LSL calculator repository makes the browser implementation inspectable.

Human accountability and refusals

Human review remains mandatory before posting, payment, lodgement, approval or period lock. Professional judgement stays with a person. A tool must refuse or escalate missing, contradictory, stale or out-of-scope facts rather than invent a result. Each product page records its specific inputs, refusal conditions, source currency limits and human decision boundary.

I publish evaluations of fixed releases on the Evaluations page. I use feedback only with recorded permission. Each evaluation states its scope and method. It is not regulatory approval or evidence beyond that evaluation.
