## Accepted upstream work

Maintainers of the projects below merged these specific changes. The merges do not establish adoption or endorsement of this portfolio, or validate its accounting calculations.

OpenAccountants, tax guides for coding agents. Pull request 85 restored the Australian BAS guide and added stale-sync integrity checks, including detection after a write. It merged on 11 August 2026 and changed 10 files. Stopping stale sync runs from overwriting guides also needs the exporter to call those checks and the repository to enforce them. Meltano SDK, a framework for Singer taps and targets. Pull request 3727 retains previously discarded OAuth refresh tokens in memory for the run without writing them to stored configuration. It merged on 8 August 2026 and changed 2 files.

Xero command line, XeroAPI’s command-line tool for the Xero Accounting API. Pull request 44 passes the --standard-layout and --payments-only flags of the balance sheet and profit and loss reports to the matching Xero SDK parameters. The two had been swapped, so --standard-layout returned a cash-basis report with different amounts. It merged on 17 September 2026, changed 3 files and added regression tests for both reports.

PyXero, a Python client for the Xero accounting API. Pull request 440 adds client-credentials authentication for Xero custom connections. It merged on 10 September 2026 and changed 4 files. Pull request 439 raises an error when a Xero call expecting JSON receives a non-JSON page with a 200 status, which the client had passed back to callers as raw bytes. It merged on 9 September 2026 and changed 5 files.

Odoo Community Association, accounting modules for Odoo. Three pull requests for Odoo 19 merged after review. Pull request 1565 stops the financial report module's link hook acting on other reports and on frames that have not loaded. It merged on 7 September 2026 and changed 2 files. Pull request 1003 fixes three online bank statement import tests that failed in the first hour after midnight UTC. It merged on 31 August 2026 and changed 1 file. Pull request 1029 adds regression coverage for automatic reconciliation of an existing statement line. It merged on 31 August 2026 and changed 1 file.

ERPNext, open source ERP software. I reported outdated and misspelt account names in its Australian chart of accounts in issue 59498. A maintainer opened pull request 59499 incorporating my commit and merged it on 27 September 2026. It changed 1 file.

ERPNext Australian Localisation, BAS, ABA payment file and BAI2 bank file extensions for ERPNext. Pull request 194 stops ABA payment files truncating ten-digit account numbers to nine digits. It now rejects the number and names the party or bank account. It merged on 7 September 2026 and changed 2 files.

LedgerSMB, double-entry accounting software. Pull request 9842 makes existing GIFI codes (Canadian tax-reporting account codes) read-only while their descriptions stay editable, with tests for both. It merged on 7 September 2026 and changed 3 files.

requests-cache, a persistent HTTP cache for Python. Pull request 1187 adds a has_content_changed attribute that reports whether a refreshed response differs from the cached copy. It compares JSON without regard to formatting or key order and reports no result when no comparison was made. It merged on 15 September 2026 and changed 7 files.

## Data and privacy boundary

The calculation engines and MCP server run locally. Installation downloads packages. If you use a cloud-backed AI host, supplied arguments, tool results and local library excerpts may be sent to that host’s model provider. Check the host’s configuration and data handling before supplying information.

The optional LodgeiT calculator adapter is separate, unreleased development code and off by default. It makes network calls only with explicit enablement, a configured base URL and an allowed host. The standard MCP server does not use it as a fallback. Website hosting and browser data handling have their own boundaries.

No client, taxpayer or production-ledger data appears in public examples. Business fixtures are synthetic; dated official-source snapshots are identified separately and do not establish current law. Client data belongs in a controlled local directory, never a public issue, repository or enquiry email.

- The ATO benchmark client data control records the zero-network runtime boundary.
- The Payday Super local file boundary, TheWIPTally local file boundary and Workpaper Review Gate data boundary state how client files are separated from public fixtures.
- The MCP client architecture describes a local stdio process. The Xero scope and credential boundary separately records that product’s read-only API and local token controls.
- The Coal LSL calculator repository makes the browser implementation inspectable.

## Supplier information for AI registers

The National AI Centre’s Guidance for AI Adoption recommends that organisations using AI keep an AI register and assess AI risk. For each component that works with an AI assistant, I publish the supplier’s side of that record: what it is, the data it handles, where a person decides, its known limits and failure modes, how it is tested and how to report a problem. Each record’s first seven rows follow the columns of the National AI Centre’s AI register template. The firm adds its own owner, use, risk assessment and review dates. Each repository has a test that holds its record to the version or published release it describes.

- Aus Accounting MCP, with answers to the questions firms put to tax-research tools
- evatt, the Xero Ledger Review Gate and the Workpaper Review Gate
- Australian Accounting Skills
- au-fpa-pack
- llm-tax-guardrails, the external prompt guide

AS ISO/IEC 42001:2023 is the Australian identical adoption of ISO/IEC 42001:2023, a management system standard for organisations that provide or use AI systems. Certification against it is voluntary and is carried out by external certification bodies, not by ISO. These records are supplier information, not a certification, an audit or a conformity assessment, and they do not establish that any organisation’s AI management system conforms to, or is certified against, the standard.

## Human accountability and refusals

Human review remains mandatory before posting, payment, lodgement, approval or period lock. Professional judgement stays with a person. A tool must refuse or escalate missing, contradictory, stale or out-of-scope facts rather than invent a result. Each product page records its specific inputs, refusal conditions, source currency limits and human decision boundary.
