# Evaluations

Explore a synthetic profit-and-cash workbook, then reproduce 3 accounting-tool evaluations at fixed releases using fabricated inputs and hand-recorded expected results.

An evaluation shows what one version did on declared fixtures. It does not prove completeness, suitability, or a professional conclusion.

For identity, source, and release assurance, see the Evidence register. Each evaluated tool is listed on the Tools page. Choose an example for any tool.

## Profit of $35,957.55. A cash shortfall of $25,160.

Lumbridge Services is a fictional maintenance business in Newcastle, NSW. Moving one $44,000 customer receipt from 14 October to 28 November 2026 leaves quarterly profit before income tax unchanged at $35,957.55 while daily cash falls to ($25,160.00) on 6 November. All amounts are AUD and every figure is fabricated.

## Review the Lumbridge case: a bounded task

This is a guided reproduction rather than a blinded trial: the expected figures are published in the table above and repeated in the template, so what it tests is whether the workbook and the instructions produce those figures for someone else. The task takes one workbook, needs desktop Excel and nothing else, and uses fabricated figures only.

- Download the sample pack and open lumbridge.xlsx in desktop Excel with automatic calculation. Note your Excel version and operating system.
- Record the on-time figures: quarter revenue, profit before income tax, October closing cash, December closing cash, and the lowest daily closing cash with its date.
- Change Assumptions!B2 from 0 to 45. Record the lowest daily closing cash and its date, the first negative date, October closing cash, December closing cash, and profit before income tax.
- Compare each observed figure with the on-time and 45-days-late columns above. Record every difference, however small.
- Restore 0, save a copy, reopen it, and confirm the base figures return.
- List each step that was unclear, each output you misread, and what you would need before a controlled trial in a workplace.

Download the blank response template (plain text), fill it in, and email it to ryan@duguid.com.au with the subject "Lumbridge review". The template asks which workbook you used and what you had already seen of the case, your environment, the scenario and any input changes, expected against observed results, whether you finished without help, defects, and your permission preferences for any later quotation. The longer 8-step guide, TRIAL.md, is inside the sample pack. The address ryan@duguid.com.au is shown as text and needs no scripts; delivery can rewrite email links, so if one does not work, write to ryan at duguid dot com dot au. Do not include client records, taxpayer identifiers, credentials or confidential files.

## Manager review gate evaluation

Runs 2 fabricated BAS packs through Workpaper Review Gate, corrects the stated failures, and reproduces READY.

Fabricated input

Two BAS workpaper packs.

Expected result

Exact NOT_READY findings, then READY after correction.

Fixed release

Workpaper Review Gate review-ready-gate/v0.1.3.

Limitation

READY is readiness for a manager, not sign-off.

Evaluation source · Primary source: Australian Taxation Office, Business activity statements

## Xero trial balance integrity evaluation

Runs 3 fabricated CSV fixtures through the movement and year-to-date balance gate without a Xero tenant.

Fabricated input

Balanced and unbalanced trial-balance CSVs.

Expected result

One accepted export and 2 explicit refusals.

Fixed release

Xero trial balance export xero-trial-balance-export/v0.1.6.

Limitation

No tenant credentials, live tenant data, or API availability test.

Evaluation source · Primary source: Xero, Accounting API Reports

## Payday Super timing evidence evaluation

Reproduces 4 evidence-timing outcomes, including at-risk, on-time, and late classifications.

Fabricated input

Four contribution and receipt-evidence fixtures.

Expected result

Exact status and due-date output for each line.

Fixed release

Payday Super Checker payday-super-checker/v0.1.3.

Limitation

Supplied evidence is classified; missing facts are not inferred.
