Four supported adoption routes

An MCP server is a standard way to hand an AI assistant a fixed set of vetted tools. github-agent-skills gives Codex and Claude Code the GitHub maintenance workflows this portfolio uses, and keeps the fabricated-data and human-review boundaries. These commands are for firms already running Claude Code or Codex; if yours is not, start with the browser calculator or send the evaluation links below to whoever manages your systems.

Needs: the two MCP commands need uv installed; the skills command needs Node; GitHub maintenance workflows need Git and PowerShell 7.

# Australian Accounting & Tax MCP server for Claude Code
claude mcp add aus-accounting -- uvx aus-accounting-mcp

# Australian Accounting & Tax MCP server for Codex
codex mcp add aus-accounting -- uvx aus-accounting-mcp

# Public Practice & Tax skills
npx skills add ryanduguid/australian-accounting-skills

# GitHub maintenance workflows for Codex and Claude Code: https://github.com/ryanduguid/github-agent-skills
git clone https://github.com/ryanduguid/github-agent-skills.git
cd github-agent-skills
pwsh -File scripts/sync-skills.ps1
