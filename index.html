Three supported commands

An MCP server is a standard way to hand an AI assistant a fixed set of vetted tools. These commands are for firms already running Claude Code or Codex; if yours is not, start with the browser calculator or send the evaluation links below to whoever manages your systems.

Needs: the two MCP commands need uv installed; the skills command needs Node.

# Australian Accounting & Tax MCP server for Claude Code
claude mcp add aus-accounting -- uvx aus-accounting-mcp

# Australian Accounting & Tax MCP server for Codex
codex mcp add aus-accounting -- uvx aus-accounting-mcp

# Public Practice & Tax skills
npx skills add ryanduguid/australian-accounting-skills

Engage

Fix the workflow before another review round.

Bring the point where a workpaper, payroll check, ledger export or AI-assisted task stops being easy to review. The useful first step is a bounded problem, not a platform pitch.

A useful first email is two or three sentences about the step that is hard to review, with no client data. That is enough to work out whether one of these tools fits and what a controlled trial with fabricated records would look like.
