Rates

Seven maintained Australian reference tables with the current value, source-reviewed date and primary material kept together.

Verify a figure against current guidance before relying on it. Historical and current values remain on the linked HTML pages. Verified is the date a figure was last checked against its primary source; last reviewed is this page’s editorial check.

Last reviewed 17 October 2026.

Each rate page keeps its own source verification date. The Excel instructions below do not renew those checks.

Use these tables in Excel

In Excel for Windows with Power Query, choose Data, Get Data, From Other Sources, Blank Query. Open Advanced Editor, replace its contents with this query and choose Done, then Close & Load. If prompted, choose Anonymous access for this public source. Microsoft’s Text/CSV guide explains the connector.

let
    Source = Csv.Document(
        Web.Contents("https://duguid.com.au/rates/super-guarantee/super-guarantee-rates.csv"),
        [Delimiter = ",", Encoding = 65001, QuoteStyle = QuoteStyle.Csv]
    ),
    Headers = Table.PromoteHeaders(Source, [PromoteAllScalars = true]),
    Rates = Table.TransformColumnTypes(Headers, {
        {"period_start", type date},
        {"period_end", type date},
        {"general_sg_rate_percent", type number},
        {"notes", type text}
    }, "en-AU")
in
    Rates

Checked in Excel for Windows 16.0, build 20527, on 17 October 2026: 8 data rows, 4 columns and the open-ended period retained.

This imports the full SG history. A rate of 12.00 means 12%; divide by 100 if a formula needs a fraction. A blank end date remains blank. Select the period that applies to your work; the latest row does not apply to every year.

Use Data, Refresh All to fetch the current CSV again. A successful refresh confirms retrieval, not source verification. Check the linked rate page’s verified date and primary source. For a completed workpaper, keep a dated values-only copy of the table and its source verification date; a live query can change on refresh.

The other six tables use the same steps with their own column types. Percentage columns hold whole percentages, as in the SG table. Each query keeps effective periods and notes, and an announced measure’s status stays text: it is not an enacted rate.
