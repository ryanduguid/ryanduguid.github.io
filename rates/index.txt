Verify a figure against current guidance before relying on it. Historical and current values remain on the linked HTML pages. Source checked is the date a table was last checked against its primary source, from the CSV’s checked_at; last reviewed is this page’s editorial check.

Each rate page shows its own Source checked date. The Excel instructions below do not renew those checks. Every row of the nine rate CSVs names the source it was checked against in source_url and the date of that check in checked_at.

All nine rate tables as one JSON file: every CSV row, with its source_url and checked_at, built from the CSVs. It is published under this repository’s licence, the Ryan Duguid Public Attribution Licence 1.0.

## Use these tables in Excel

Show the Power Query steps

In Excel for Windows with Power Query, choose Data, Get Data, From Other Sources, Blank Query. Open Advanced Editor, replace its contents with this query and choose Done, then Close & Load. If prompted, choose Anonymous access for this public source. Microsoft’s Text/CSV guide explains the connector.

```
let
    Source = Csv.Document(
        Web.Contents("https://duguid.com.au/rates/super-guarantee/super-guarantee-rates.csv"),
        [Delimiter = ",", Encoding = 65001, QuoteStyle = QuoteStyle.Csv]
    ),
    Headers = Table.PromoteHeaders(Source, [PromoteAllScalars = true]),
    Rates = Table.TransformColumnTypes(Headers, {
        {"period_start", type date},
        {"period_end", type date},
        {"general_sg_rate_percent", type number},
        {"notes", type text},
        {"source_url", type text},
        {"checked_at", type date}
    }, "en-AU")
in
    Rates
```

Checked in Excel for Windows 16.0, build 20527, on 17 October 2026: 8 data rows, 4 columns and the open-ended period retained. The source_url and checked_at columns were added on 3 November 2026 and loaded in build 20625 on 14 November 2026.

This imports the full SG history. A rate of 12.00 means 12%; divide by 100 if a formula needs a fraction. A blank end date remains blank. Select the period that applies to your work; the latest row does not apply to every year.

Use Data, Refresh All to fetch the current CSV again. A successful refresh confirms retrieval, not a source check. Check the linked rate page’s Source checked date and primary source. For a completed workpaper, keep a dated values-only copy of the table and its Source checked date; a live query can change on refresh.

The other nine tables use the same steps with their own column types. Percentage columns hold whole percentages, as in the SG table. Each query keeps effective periods and notes, and an announced measure’s status stays text: it is not an enacted rate.
