Privacy and site use

This notice explains how this website handles browser calculations, hosting and feedback.

Published 12 September 2026. Last reviewed 21 September 2026.

On this page

Browser calculations

The website's calculators process the figures you enter in your browser. They do not send those figures to a server or save them in browser storage. Download any results you want to keep before leaving the page. Downloaded files stay wherever you save them.

The accounting-question search also runs in your browser. It does not send search text to a search service. It does place the search term and topic in the page address so a filtered list can be bookmarked or shared, which means the term appears in your browser history and in any address you pass on.

Cookies and analytics

The website's own code does not set cookies or include advertising pixels. Its fonts, images, and application scripts are served from this domain.

No analytics script is delivered. Cloudflare Web Analytics was removed from this site on 20 September 2026, so the site owner receives no page-view reports. GitHub Pages and Cloudflare still process requests to host and protect the site, as the Hosting section below describes.

Email Address Obfuscation is disabled so email links work without scripts. The address is public in the HTML pages, their plain-text alternates, and the machine-readable index. The contact page also spells it out for anyone whose browser does not open an email app.

Cloudflare also asks browsers to report network errors to Cloudflare for seven days and to prefetch pages you are likely to open next (the nel, report-to and speculation-rules response headers). Neither carries the figures you type into the calculators. A prefetched or shared page address can carry question-search terms, because the search places them in the address; do not put confidential information in a search you may share or leave in your history.

Cloudflare also supplies visitor-verification code as part of page delivery. Both additions are made after the files leave this website's source and are served from this domain. Cloudflare may process technical request and browser-verification information and may set its own security cookies; see Cloudflare's cookie documentation. That processing is separate from the figures the calculators handle, which their own code works out in your browser without sending them to a server.

When you select Human or Machine view, your browser saves that display preference on this device. The preference is not sent to a server. You can change it with the view switch or remove it by clearing this site's browser storage.

Hosting

GitHub Pages hosts this website's files, and Cloudflare delivers them to your browser. These providers process technical information about visits, which may include IP addresses, request details, and security or performance data. See the GitHub Privacy Statement and Cloudflare Privacy Policy for their handling of that information.

Feedback and external links

If you email me, I receive your email address and the content you send. Use fabricated examples when reporting a problem. Do not include taxpayer information, client files or other confidential records. An email stays in my mailbox until I delete it, GitHub keeps issues public in its own systems under its terms, and I cannot delete copies other people hold.

GitHub issues are public. Links to GitHub and other websites take you to services with their own privacy policies. Software you download or install has its own documented data handling; this notice covers the website.

For questions about this notice or information you have sent me, email ryan@duguid.com.au. To ask what personal information I hold, have it corrected, or complain about how I handled it, email that address, or take a complaint about the handling of personal information to the Office of the Australian Information Commissioner. Other project links are on the Contact page.

AI crawlers and citation

The site's robots.txt names each crawler and its treatment. Search indexing and the fetches an assistant makes to answer or cite for a user are allowed for the agents it names, and Google-Extended is allowed so Gemini grounding can cite the site. Common Crawl (CCBot) and Bytespider are allowed to crawl the open web, while the closed-lab training crawlers it names, GPTBot and ClaudeBot among them, are disallowed. The machine-readable index and the full page text are published for citation, and robots.txt is the current policy if this summary and the file ever differ.

If an AI answer misquotes this site, email ryan@duguid.com.au with the page address and the quoted text. Use fabricated examples only; do not send client records or taxpayer information.
