# Privacy and site use

This notice explains how this website handles browser calculations, hosting and feedback.

Published 12 September 2026. Last reviewed 18 September 2026.

## Browser calculations

The website's calculators process the figures you enter in your browser. They do not send those figures to a server or save them in browser storage. Download any results you want to keep before leaving the page. Downloaded files stay wherever you save them.

The accounting-question search also runs in your browser. It does not send search text to a search service.

## Cookies and analytics

The website's own code does not set cookies or include advertising pixels. Its fonts, images, and application scripts are served from this domain.

Cloudflare adds a performance analytics script when delivering pages. The site's browser security policy is configured to block that script. This is separate from the technical request information handled by the hosting and delivery providers below. See Cloudflare's analytics documentation for how its script works.

Cloudflare also rewrites email addresses on delivery to slow automated address collectors, and adds its own visitor-verification code. The rewriting covers the HTML pages only: the plain-text alternate of each page, the machine-readable index and the downloadable review template are served as plain text and carry the address as written. Both are added after the files leave this website's source and are served from this domain, and neither reports anything to the site owner. Cloudflare may set its own security cookies when it delivers a page; see Cloudflare's cookie documentation. The contact page and the Lumbridge review task spell the address out as well, for anyone whose browser cannot run the rewriting.

When you select Human or Machine view, your browser saves that display preference on this device. The preference is not sent to a server. You can change it with the view switch or remove it by clearing this site's browser storage.

## Hosting

GitHub Pages hosts this website's files, and Cloudflare delivers them to your browser. These providers process technical information about visits, which may include IP addresses, request details, and security or performance data. See the GitHub Privacy Statement and Cloudflare Privacy Policy for their handling of that information.

## Feedback and external links

If you email me, I receive your email address and the content you send. Use fabricated examples when reporting a problem. Do not include taxpayer information, client files or other confidential records.

GitHub issues are public. Links to GitHub and other websites take you to services with their own privacy policies. Software you download or install has its own documented data handling; this notice covers the website.

For questions about this notice or information you have sent me, email ryan@duguid.com.au. Other project links are on the Contact page.
