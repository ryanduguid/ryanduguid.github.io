# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it via private vulnerability reporting on GitHub or by email to ryan@duguid.com.au.

Please do not report security vulnerabilities through public GitHub issues.

A valid report is acknowledged within seven days, the window set by the [account-level security policy](https://github.com/ryanduguid/.github/blob/main/SECURITY.md), and the fix and disclosure timeline are then coordinated with the reporter through standard commit and release processes.
